# My Chatbot Project

## Description
This is a simple chatbot that provides definitions, synonyms, and antonyms for words. It uses the NLTK library to access the WordNet database for word definitions and relationships. The chatbot is designed to assist users in understanding words better and enhancing their vocabulary.
